# imchlite

## Download

Download the latest release binary into the current directory.

Linux (sh):

```sh
curl -fsSL https://raw.githubusercontent.com/vigovlugt/imchlite/main/scripts/download-latest.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/vigovlugt/imchlite/main/scripts/download-latest.ps1 | iex
```

Both scripts extract the binary into the current directory, overwriting an existing one, and discard the archive.
